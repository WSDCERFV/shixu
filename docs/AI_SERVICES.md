# AI 服务配置与对话反馈

## 快速连接

在 API 管理点击“添加供应商”，先选模板，再选账户有权限使用的模型，填写自己的 API Key 后保存。模板只预填配置，不会注册账号、购买额度或自动发送测试请求。选择列表中的“规划使用中”即可用于对话。

内置 OpenAI、DeepSeek、通义千问中国站、智谱标准 API，以及可选的 OpenAI 语音转写模板。模板中的模型 ID 可以直接编辑；其他供应商选择“自定义 / 其他兼容服务”，填写 Base URL、协议、模型 ID 和密钥。

自定义服务需要兼容 Responses 或 Chat Completions，并支持 JSON 计划输出；Anthropic 原生 Messages 协议不在本版支持范围内。百炼地域、业务空间和智谱 Coding 套餐的地址可能不同，应以自己控制台的地址为准。

## 内置规划技能与本地排程

[shixu-planner](../desktop/skills/shixu-planner/SKILL.md) 随安装包分发，每次调用模型前加载，不需要手动安装或复制到聊天框。它要求利用已有日程和手动草案，非关键缺失使用明确假设，只有缺少关键目标、存在不可解的硬约束等情况才提出必要问题。学校调整另有小范围规则，不改动未提及的课程。

应用先计算空闲时段，压缩历史中重复的计划 JSON，保留当前输入与最新草案。模型生成后再进行本地时间检查：flexible 安排可在同一天、指定窗口内移动，日期和时长保留；固定时间与手动时间不做自动避让。每日规则检查未来 31 天中的执行日期，使用同一个可行时刻；长期目标的阶段本身没有具体占用时间。

课表默认只作占用参照。模型只收到所选日期起两周及明确相关日期的精简课程名称和时段；完整课程内容、其他教学周和未涉及的课程草案留在本地。用户明确要求调课时，应用根据课程名称和原日期限定本轮可修改编号，只发送对应课程详情，最多处理 30 次。没有日期时采用所选日期或最近一次课程，只有明确要求批量处理才扩大范围。无法明确匹配时，可用完整课程名称和原日期，或在课程详情点“让 AI 调整”后说明要求。

本地还会过滤未授权的课程移动、删除或重复复制；调整课程时间时保留原内容、教师、教室、优先级和标签。模型只返回本轮的增改删，应用合并并保留未涉及的草案；已经确认的课表不会被重新混进下一轮待确认任务。旧版遗留的已确认课程副本在恢复对话时清理，不修改已保存课表；手动未确认修改继续保留，不能明确识别的旧课程建议默认取消勾选供核对。

仍有冲突时会明确指出日期、时间和冲突事件，草案继续保留供修改。手动修改或确认前会按最新日程再检查，普通/极简模式均阻止冲突的 AI 草案直接写入。学校实际课表导入保留原来的冲突提示和预览流程。

技能和规则不能替代模型的理解能力、提供商可用性及用户对实际条件的核对；网络检查与排程检查使用本地夹具验证，没有使用真实付费模型评价所有自然语言场景。

## 对话反馈

发送后立即出现状态卡片。应用会显示需求是否已发送、等待或生成阶段、经过时间以及逐步返回的回复。点击“停止生成”会取消本次请求，原日程和已有草案保留；失败原因保留在对话中，可以重新发送，未发送的输入也会保留。

思考区域只显示服务实际提供的摘要或思考内容；没有提供时显示处理进度，不编造内部推理。生成中可以滚动、选中文字、展开或折叠，新增内容不会重置阅读位置。开始回答时自动折叠一次；再次手动展开后，后续输出与完成状态不会反复将它收起。OpenAI 模板通过 Responses 请求公开的 reasoning summary；其他兼容服务可能返回 reasoning_content，界面会明确标为“模型返回的思考”。这些内容与对话一样保存在本地，不会被加入后续模型消息。

回复中的任务会在完整接收并通过校验后成为待确认草案。流式传输中断、取消或格式错误不会生成半份日程。用户确认后才写入。

## 响应策略

供应商详情的“回复方式与兼容选项”可选择快速、均衡（默认）、深入。已知兼容的官方 OpenAI / DeepSeek 模型会据此调整推理开销，日常安排可优先用快速或均衡。复杂目标可选深入，等待和用量可能增加。自定义网关和未知模型沿用服务端默认参数，避免发送不兼容的推理选项。

官方 DeepSeek 的均衡 / 深入模式采用 64K 输出预算，为思考和最终回答保留空间；快速模式保持 16K。预算是上限，实际用量由模型输出决定。若服务返回输出额度耗尽，界面会明确说明它属于截断而非等待超时；自定义中转的额度需按该服务的设置调整。

## 兼容选项

在供应商详情展开“回复方式与兼容选项”，可以关闭流式输出，等待阶段仍有状态反馈。思考摘要需要模型支持，不支持时可以取消“请求模型的思考摘要”。首次思考或回复最多等待十五分钟；连接建立后连续五分钟没有任何数据时视为连接可能中断。SSE 保活注释和非流式空行计为连接活动，不会误判成已断线，也不会冒充思考内容。

持续收到新的思考或回复会延长等待，不再设置整轮十分钟的固定截止时间。只有保活、连续十五分钟没有新思考或回复时，仍会停止并说明原因，避免无休止等待。用户随时可以停止。收到完成信号后会立即返回，不继续等网关关闭连接。HTTP 429/502/503/504 在开始输出前最多重试一次；不会在中断后自动重新生成整份回复。服务端或中转商自己设置的连接时限仍可能结束请求，客户端无法代替服务端继续生成。

更换供应商域名后，需要重新填写对应密钥，避免把原供应商密钥发给其他服务。编辑同一服务并留空密钥会保留已保存的密钥。软件不显示或导出已保存的密钥。
