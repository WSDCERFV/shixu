# 时序 Shixu v0.9.3

本次更新让批量编辑、水课设置和操作反馈更直观，并为 AI 排程加入日常生活预留。包含此前未单独公开的 0.9.0–0.9.2 开发版本改进。

## 下载与升级

- **安装使用**：下载 `Shixu-0.9.3-setup-x64.exe`，保存并退出旧版后直接覆盖安装，无需先卸载，保留本机日程、对话和服务配置。可在安装前选择目录。
- **免安装体验**：下载 `Shixu-0.9.3-preview-win-x64.zip`，解压整个文件夹，运行“时序预览.exe”。更新预览版时，请完整保留并迁移原“预览数据”文件夹。
- **源码**：下载 `Shixu-0.9.3-source.zip`，按 README 的步骤运行或构建。
- `SHA256SUMS.txt` 用于校验下载文件；`latest.yml` 和 `.blockmap` 用于安装版的应用内更新。

支持 Windows 10 / 11 x64。安装包与预览版均包含运行环境，新用户首次打开没有预置测试计划。

## 本次主要改进

- **独立水课管理框**：在课表导入中搜索课程，设置今天起的后续课次或单次课。按课程、教师和学期区分，显示固定、部分并行或全部并行状态。课程时间和原信息保留，可撤销。
- **直接框选与批量操作**：移除“框选模式 / 完成选择”开关。空白处直接拖框，Ctrl / Shift 点击加选或取消，也可按住修饰键从事件上拉框；选中后才显示操作栏。Ctrl+A 全选当前范围，Delete 删除，Esc 取消选择，Ctrl+Z 撤销。文本输入保留文字自身的快捷键。
- **醒目的操作提示**：成功、校验失败、导入结果和服务出错显示在可拖动关闭的提示窗中。错误保留到手动关闭，后来的成功消息不覆盖错误。独立详情窗使用同一套提示。
- **AI 生活预留**：内置规划技能升级至 1.1，默认预留早餐、午餐、午休、晚餐、夜间睡眠和下课后 15 分钟出行。午餐默认 12:00–13:00，午休默认 13:00–13:30。模型空闲时段与本地排程共同遵守这些预留；明确个人作息可调整。不会批量新增占位任务或改动既有课程。
- **多周总览与完整周视图**：可同时浏览 4 / 8 / 12 周，调整时间轴高度和每行最多周数，点击跳周；统一工具栏、日期和时间轴排版，长标题省略、短事件使用色块，小窗口自动减列。周计划支持完整显示或内部滚动。
- **自定义工作台**：关闭不用的功能，添加、移动、缩放或移除总览模块，普通和极简模式分别保存布局。自定义总览中的 AI 同样支持日程内预览和确认。
- **旧课表日期校验**：识别已保存课程的学期与日期疑点，先对照预览再确认校正。保留课程 ID、教室、教师和心得，支持撤销与保存失败回退；不在启动时重新抓取，也不自动覆盖个人课表。

## 验证与使用说明

本地已通过 86 项单元检查、13 组隔离桌面检查，以及安装版和免安装版的打包运行检查。覆盖保存失败回退、撤销、未保存心得、课程保护、240 节模拟课程、生活预留和 AI 草案确认。测试未修改真实个人日程，未使用真实学生账号、模型密钥或邮箱验证外部服务质量。

安装版可以在“设置 → 应用更新”检查新版，按提示下载、校验并保存退出升级。下载和安装仍需手动确认。当前发行文件未代码签名；安装版与预览版的数据目录分开。使用与数据说明见仓库 README。
