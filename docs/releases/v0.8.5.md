# 时序 Shixu v0.8.5

这次更新集中改进 AI 规划的反馈、稳定性和课表保护，同时加入应用内更新。包含此前未单独公开的 0.8.1–0.8.4 开发版本改进。

## 下载与升级

- **安装使用**：下载 `Shixu-0.8.5-setup-x64.exe`，退出旧版后直接覆盖安装，无需卸载，保留个人日程、对话和配置。安装向导支持选择目录。
- **免安装体验**：下载 `Shixu-0.8.5-preview-win-x64.zip`，解压整个文件夹，打开“时序预览.exe”。升级预览版时，请保留并迁移原“预览数据”文件夹。
- **源码**：下载 `Shixu-0.8.5-source.zip`，按 README 的步骤运行或构建。
- `SHA256SUMS.txt` 提供下载文件的校验值；`latest.yml` 和 `.blockmap` 供安装版检查与下载更新使用。

支持 Windows 10 / 11 x64，安装包和免安装版均包含运行环境。安装版与预览版的数据目录分开，预览记录不会自动转入安装版。

## 本次主要改进

### 课程保护与规划范围

- 修复整学期课表确认后，下一轮规划再次混入全部课程、产生课程与自身冲突的问题。
- 普通排程将课程视为已占用时间。仅明确涉及的课程允许提出调课建议，本地过滤越界修改、删除和重复复制。
- 单次调课保留教师、教室、内容、标签及其他课程；模型只返回本轮增改删，未涉及的草案由应用保留。
- 近期精简占用发送给模型，完整学期仍留在本地校验，减少重复上下文。
- 清理旧对话中的重复预览，保留手动未确认修改；导入保存失败可回退并重试。已由旧版确认保存的错误调课仍须按实际课表核对，本次不会擅自覆盖个人记录。

### AI 对话与响应

- 发送、等待、逐步回复、耗时、停止及失败重试均有反馈；内置规划技能结合空闲时段和本地冲突检查生成可编辑草案。
- 修复思考内容反复回弹，保留滚动、文字选择和手动展开状态；自动折叠只触发一次。
- 识别连接保活，首次输出等待延长至十五分钟。持续返回思考或回复时不再受整轮十分钟限制，长时间无数据或无进展仍会停止并提示原因。
- 官方 DeepSeek 思考模式采用 64K 输出预算，明确区分输出额度耗尽与等待超时。
- API 管理提供常用供应商与模型模板，也支持自定义兼容服务。

### 课表抓取与应用更新

- 东南大学登录支持延迟加载的表单，避免反复填写；登录后按学校返回的真实名称选择学期，暑期额外确认，错学期停止读取。
- 整学期读取校验分页完整性，略过已结束课程，先预览再确认，启动时不自动抓取。
- 设置增加“应用更新”：检查新版、更新说明、下载进度、取消与文件校验，保存成功后再退出升级。启动检查默认关闭，不自动下载或在普通退出时安装。

## 验证与使用说明

已通过 71 项单元测试、8 组隔离桌面检查，以及安装版和免安装版的打包运行验证。使用 240 节模拟课程检查了普通规划、局部调课、越界输出、保存失败和旧对话重启恢复；未使用真实模型密钥、学生账号或邮箱验证外部服务质量。

AI 功能需要自行配置兼容服务和 API Key。当前发行文件未代码签名，Windows 可能显示未知发布者。应用退出或电脑休眠时不调度任务和邮件提醒；自定义上传背景目前只在当前打开期间有效。完整功能、数据目录与构建说明见仓库 README。
