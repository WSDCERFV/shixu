# 数据与网络行为

## 保存在本机的内容

安装版使用当前 Windows 用户的 `%APPDATA%\Shixu`，记录日程、计划、聊天、草案、偏好及备份。缓存、日志与崩溃转储使用 `%LOCALAPPDATA%\Shixu` 的独立目录，临时文件使用系统临时目录。

免安装预览使用程序旁的“预览数据”。开发和自动化检查可以用绝对 `SHIXU_DATA_DIR` 覆盖全部运行路径。这些目录不应上传到 GitHub。

API Key 与邮件授权码由 Electron safeStorage 调用 Windows 系统加密，保存在本机的 `secrets.json`。它不是跨设备密钥保险箱，不保证换电脑或 Windows 用户后仍可解密。

## 哪些操作联网

| 操作 | 会发送的内容 | 接收方 |
| --- | --- | --- |
| AI 对话与规划 | 当前输入、当前对话上下文、相关任务的名称/日期/时间/优先级/标签/具体内容及计划草案 | 你选择的 AI 供应商 |
| Windows 系统听写 | 由 Windows 的听写功能处理 | 由 Windows 设置决定 |
| 可选云端转写 | 本次录音 | 你选择的转写供应商 |
| 学校登录与抓取 | 你主动填写的账号密码、学校网站所需会话信息 | 学校认证与课表网站 |
| 邮件提醒 | 收发邮箱、任务名称、时间与具体内容 | 你配置的 SMTP 服务及收件邮箱 |

任务的“我的感受”字段不会被自动加入规划上下文或提醒邮件。你主动在聊天输入中填写的文字仍会作为聊天内容发送。云端录音不保存为本地音频文件；学校登录使用临时会话，不把学校密码写入日程和聊天记录。

## 运行与备份

应用退出或电脑休眠期间不调度提醒和邮件。失败邮件会记录状态，不自动重复发送。开机启动由用户单独选择，不会因为安装或第一次打开自动开启。

应用写入会保留上一份有效 `.bak`。主记录损坏时会尝试恢复并保留损坏原件；无法安全读取时停止启动，不用空白数据覆盖原文件。

备份请先退出应用，再复制整个个人数据目录。卸载默认保留安装版个人数据；免安装版删除前请先备份。报告问题时建议用虚构任务复现，并隐去个人信息。
