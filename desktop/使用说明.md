# 时序桌面版 0.8.5

先保存并退出旧版，再打开“Shixu-0.8.5-setup-x64.exe”，直接覆盖升级，无需先卸载。安装向导会在安装前提供目录选择，可选择其他磁盘或包含中文、空格的路径；请使用单独的应用文件夹。安装后通过桌面或开始菜单的“时序”启动，也可从 Windows“已安装的应用”卸载。支持 Windows 10 / 11 64 位，不需要另行安装 Node.js。安装包包含完整运行环境，安装与基本日程管理可离线使用。

个人数据独立于安装位置，升级、卸载和重装默认保留个人记录。全新 Windows 用户首次启动没有任务、长期目标、对话或 API 配置；已经使用过旧版的同一 Windows 用户会继续看到原来的真实记录，这属于升级保留。安装包只包含明确列出的应用文件，不包含开发测试记录、邮箱或密钥。当前安装程序尚未代码签名，Windows 可能显示未知发布者提示。

## 文件存储位置

- 日程、长期计划、对话、偏好和有效备份：`%APPDATA%\Shixu`，继续兼容旧版位置。
- API Key 与 SMTP 授权码：同一目录内的 `secrets.json`，由当前 Windows 用户的系统加密保护，不以明文写入日程。
- 浏览器缓存：`%LOCALAPPDATA%\Shixu\Cache`；运行日志目录：`%LOCALAPPDATA%\Shixu\Logs`；崩溃转储目录：`%LOCALAPPDATA%\Shixu\CrashDumps`。日志目录可能为空。
- 临时文件使用系统临时目录下的 `Shixu` 子目录。学校登录会话不持久保存，账号密码不进入日程文件。

上述路径由当前 Windows 用户的系统目录解析，不依赖安装磁盘、启动位置或开发者电脑的用户名。应用不在安装文件夹内写个人数据，所以普通用户可从只读的安装目录运行。目录无法创建或写入时会提示实际路径并停止启动，不会悄悄切换到空白数据目录。导出文件仍保存在你主动选择的位置。

备份时请先退出应用，再完整复制 `%APPDATA%\Shixu`；不要仅复制安装目录。系统加密的密钥不能保证跨电脑或跨 Windows 用户解密，换电脑后需要重新填写密钥。卸载保留数据，不会主动清空该目录。

首次打开有 7 步基础引导，可拖动、关闭或直接跳过。新用户从空白日程开始；AI 输入区保留可修改的文字示例，课表页保留格式模板，示例不会直接写入个人日程。升级时会清理未修改的旧版内置示例任务；修改过或写过心得的示例会保留为个人任务，自己确认过的任务和真实课表会保留。

## 普通与极简模式

顶部“普通模式 / 极简模式”随时切换，软件记住上次选择。默认继续使用普通模式，原有功能和页面保留；两种模式共用同一份个人日程、API、课表和对话。

极简模式侧栏只有总览、API 管理和设置。总览只保留今日/他日计划、周计划和 AI 对话，文字与语音共用一个输入框。需要时展开“历史对话”继续以前的规划；语音默认聚焦输入框，再按 Win+H 听写。

AI 的任务草案直接显示在周计划，原有任务淡显，新增、修改及删除都有待确认标记。可点击草案在详情侧窗修改名称、时间、标签和具体内容，也可直接拖动草案或边缘调整时间。独立桌面详情窗同样只更新草案，不会提前创建任务。可再次输入需求让 AI 调整，等待回复时填写的手动修改会保留。最后点击周计划里的“确认安排”统一写入；“取消本次”保留原日程。跨周建议会提供周次入口，未补全的草案可从“补全”入口继续编辑。普通已保存任务仍按原来的详情方式编辑。

课表导入在极简模式的“设置 → 课表导入”中展开，保留东南大学账号抓取及其他学校 CSV / ICS 导入。点击“在时间表中预览 / 调整”后，回到总览检查课程草案，再确认或取消。专注、统计和每日标语选项在极简设置中隐藏，切回普通模式后恢复原有设置。长期/每日计划草案按需在 AI 面板中展开检查，不在总览额外摆放统计卡片。

在“设置 → 应用启动”可勾选开机自启动，默认为关闭，更改后立即反馈并应用到当前 Windows 用户。这里指登录 Windows 后打开应用。开发环境和隔离测试环境不会修改真实开机启动项。卸载会移除当前用户的本应用启动项；升级或更换安装目录会维护已经开启的启动路径，不会为未开启的用户自动启用。

## 使用帮助与主题

侧栏“使用帮助”打开按功能分类的教程：日程、任务详情、AI、长期与每日计划、专注、课表、API、邮件、皮肤与统计。每个小教程只讲对应功能，可以随时结束，完整看完后会记录状态。顶部“当前页教程”可直接学习正在使用的页面；设置里也保留帮助入口。需要从头了解软件时，可自行选择“重新体验首次引导”。

浅色主题采用雾灰底色、柔和蓝绿色强调色、配套的图标和图表颜色。面板保留透明效果，并提高浅色下的可读性。深色主题保留星空蓝配色，自定义强调色会在浅色下自动降低亮度以保证文字对比；独立详情窗也会同步主题与强调色。

## 时间表与独立详情窗

点击周计划中的事件，左侧对应日期及任务会同步选中；点击今日/他日计划也会选中周计划里的事件。两处均有明显选中标记，并滚动到对应位置。事件标题保持白色，完整名称可在详情中查看。

周计划上方可切换“1 小时 / 格”和“2 小时 / 格”，并独立调整日历比例。比例与应用整体缩放分别保存。较长的时间轴在周计划面板内滚动。

双击事件进入时长编辑，拖动上下边缘后仍保留编辑状态；可继续在浮窗输入精确到分钟的起止时间。“应用时间”保存并继续编辑，“完成编辑”或点击其他位置保存并结束，Esc 取消本次尚未应用的修改。无效时间会提示并保留编辑窗口。

事件或计划详情右上角点击“独立”，可变为真正的桌面小窗；也可拖动详情标题移出应用边缘。拖动独立小窗标题即可移到应用外，并可调整大小。修改后点击保存同步回主窗口；“放回应用”恢复右侧详情栏，关闭只收起窗口。普通任务、长期目标和每日计划共用此功能。

## AI 对话和任务规划

在左侧“API 管理”添加供应商，选择 OpenAI、DeepSeek、通义千问或智谱模板后，选择模型并填写自己的 API Key。预填的地址、模型均可修改；其他兼容服务可选自定义模板。规划服务支持 Responses（需要结构化输出支持）或 Chat Completions（需要 JSON 模式支持），点击“规划 · 使用”选择默认服务。可咨询建议、生成任务、制定长期目标或常驻每日计划，也可继续要求修改。AI 不直接更改日程；检查草案、阶段清单、时间冲突和内容后点击确认。

发送后会立即显示发送状态、处理进度和耗时，回复逐步显示。接口提供的思考摘要或思考内容会在展开区域显示，开始回答后自动折叠；未提供时只显示处理进度。可以停止生成，失败时在对话中查看原因并重新发送。取消、中断或格式错误不会把部分结果写入日程。

已内置时序规划技能，无需另行安装。助手优先根据已有日程与空闲时段提出方案，非关键细节使用明确假设。可调整时间会尝试在同一天避让冲突；固定时间和手动时间会保留。若仍存在重叠，先修改草案或取消勾选相关项，再确认安排。每次手动修改都会重新检查，取消和失败均保留原日程。每日规则预览检查最近 31 天，更多日期仍需结合实际安排核对。

输入框下方“查看输入示例”可选择安排学习、先聊建议或调整已有计划。示例只填入可编辑文字；已有文字会保留并追加。点击发送才请求 AI，确认草案后才写入日程。AI 小教程也提供可填入的示例，不会自动发送请求。

具体步骤由模型生成，草案中可以手动编辑。现有任务的心得不发送给规划模型。AI 助手左边列出历史对话，按最近修改时间排列，可以新建、改名、删除或撤销删除。对话、输入到一半的补充、可编辑草案和已确认任务的关联记录保存在本机；重启后点击原对话可继续调整。不同对话各自保留草案，AI 请求只包含当前对话的上下文与最新日程。最多保留 100 个对话，容量不足时会提示，不自动删除旧对话。删除对话不会删除已经确认的任务或计划。

## 语音输入与口述心得

默认采用 Windows 系统听写，无需在本应用配置语音 API。点击 AI 输入区的语音按钮或任务详情的“口述心得”，输入框会获得焦点，再按 Win+H 开始系统听写。需要联网、可用麦克风以及系统支持的输入语言。Windows 自带的识别与聊天 AI 规划是两个用途。

如果希望在应用内录音、结束后统一转写，可把语音输入方式改为“云端语音识别”。另添加语音供应商，协议选 Audio Transcriptions，填写转写模型和密钥，再点击启用。音频交给所选供应商处理，不保留本地音频文件。识别文字可以修改后写入；心得仍需点击任务保存。云端转写支持流程已经通过本机模拟服务测试，实际识别质量由所用服务决定。

## 长期目标、每日计划与统计

左侧“长期与每日”用切换按钮分类查看两类计划，统计页面也采用相同方式。卡片上直接保留“编辑、AI 继续拆解、删除计划”。点击卡片主体会打开较大的详情浮层，展示目标、步骤、阶段进度、关联行动和创建/修改时间；点击“编辑”在右侧打开表单。详情浮层和编辑栏都支持拖动与关闭。切换编辑的计划或任务时，尚未保存的填写内容会在当前打开期间保留。

制定计划和检查 AI 草案时，字段会标注“必填”或“选填”。长期目标需要名称、开始日期与截止日期；每日计划需要名称、开始日期、每日起止时间，并至少选择一个执行星期，结束日期可以留空。状态与优先级有默认值，完成标准、标签、说明与阶段清单可以选填。阶段格式为“YYYY-MM-DD | 阶段目标”，添加时每行的日期与目标都需完整。勾选详情中的阶段会立即记录进度，其他修改需要点击“保存计划”。普通任务详情中也能关联长期目标。

每日计划可以设置执行星期、时间与起止日期，结束日期留空表示常驻。桌面版自动补齐未来 30 天，切换日期或重新打开时继续补齐；相同日期不会重复创建。可以单独修改或删除某天的任务，后续修改规则会保留已完成和单独调整过的实例。暂停或删除重复规则，只移除未来尚未完成、没有单独调整的实例，历史记录保留。删除单次任务支持撤销。

统计页面显示从首次记录起的陪伴天数、当前保留的真实完成任务，以及长期目标与每日计划分类。长期目标的阶段进度、日程行动仍由用户确认，AI 不会替用户标记完成。

## 专注与结束反馈

专注页面显示本周与累计专注小时、每周实际专注柱状图，以及按完成次数统计的常用模式。可直接修改专注、短休和长休时长。已开始的一轮保留原时长，新设置从下一轮生效。暂停、重置、切换模式不补算未完成的一轮。

专注和休息结束后，可弹出可拖动的小窗，并播放可关闭、可调音量的轻柔提示音。计时小窗与任务提醒小窗互相独立。旧版本升级时，只能从旧版本还保留的计时记录恢复累计值；从本版开始的累计专注值会持续保留，按日详情保留最近 100 天。

## 东南大学与其他学校课表

“课表”默认使用东南大学账号抓取。填写学生账号 / 一卡通号及统一身份认证密码，点击“爬取我的课表”。独立的学校窗口会等待动态登录表单加载，自动带入账号密码，不需要再次输入；验证码、手机号或二次认证需在学校页面完成。首次无验证码时可尝试提交一次，不会因密码错误反复提交。若学校要求校园网 / VPN，先按学校方式连接再重试。

进入本科生“我的课表”后，窗口上方会列出学校返回的真实学期名称和编号，不会自动读取网页默认选中的学期。选择要导入的学期，核对第一教学周周一并勾选确认，再点击“读取所选学期整学期课表”。已知秋春学期按名称匹配内置校历；未知学期需自行对照校历填写。暑期或短学期无默认日期，需要额外确认。不会仅凭学期编号的最后一位猜测季节；如果学校返回的课程学期不符，会停止导入并提示。

抓取读取指定学期的整份课表，再展开周次与日期，只保留尚未结束的课程，正在上课的课程也保留；已经结束的课程不会新导入，也不会删除原来保存在本地的历史记录。预览会显示课程总数、略过的过期课程、新增、重复、错误和冲突。点击“在时间表中预览 / 调整”可以像 AI 规划一样，对照现有日程查看并逐条编辑，确认后才写入本地。整学期课程按每页 20 次显示，可按课程名或日期查找；确认会保存所有勾选课程，包括其他页。

在课表预览对话中，可告诉 AI 哪门课、哪一天需要改时间，也可直接手动修改。AI 只改本轮相关的课程，其余课程与手动修改保留；每轮最多处理 30 次课程，可按日期分批调整。仍须检查草案并点击确认。保存后课表页会显示反馈，可从缓存卡片再次“预览 / 调整课表”；更新已有课程不会重复新增相同记录。临时调课和法定节假日补课需按学校通知核对。

抓取失败、关闭登录窗口或取消预览不会清空原日程。只有点击抓取按钮才联网，启动软件和进入课表页面不会打开学校网站。账号和密码不保存，学校登录使用单独的临时会话，窗口关闭后清理。节次采用东南大学 2024 年秋季起的作息表。本版学校登录与课表接口使用本地模拟验证，尚未使用真实学生账号验证学校当前登录流程，遇到网站变更会显示失败信息。

切换“其他学校”后使用学校导出的 CSV / ICS 文件，也可粘贴文本。东南大学页面也保留“备用：从文件导入”。先预览检查新增、重复、错误与冲突，再确认保存。不同学校的记录可以并存。

CSV 支持两类列：课程、日期、开始、结束、教室、教师；或者课程、星期、周次、开始、结束、教室、教师。教室和教师可选，建议使用 UTF-8 编码。周次可以写 1-16、1,3,5 或 1-16单周；按周次导入前设置第一教学周周一。页面可下载 CSV 模板。文件导入也会略过已经结束的课程，并支持同样的可编辑时间表预览。

ICS 支持带 DTSTART/DTEND 的当天课程，以及日/周重复、排除日期与中国时区或 UTC 时间。不支持的时区、跨天课程或复杂重复规则会列为未解析项目，不会静默填错时间；可改用具体日期 CSV。每次最多导入 2000 次课程。

## QQ 邮件提醒

可使用一个专用发件 QQ 邮箱。在 QQ 邮箱设置中开启 SMTP 并生成授权码，在本应用设置中填写：smtp.qq.com、465（SSL），发件邮箱、授权码和收件邮箱。授权码不是 QQ 登录密码。点击“应用并保存”，再点击“发送测试邮件”；测试会实际向填写的默认收件邮箱发一封邮件。

邮件全局启用后，还需要在每项任务详情勾选邮件提醒。统一收件邮箱只在设置中填写一次；任务里的邮箱留空会自动使用统一邮箱，只有某个任务需要发往其他邮箱时才单独填写。详情会显示本次将使用哪个邮箱。可设置提前时间。邮件包含名称、时间和具体内容，不发送心得。发送记录中的“已交给发件服务器”不代表对方一定已收到，请检查收件箱和垃圾箱。

事件详情中的“配置邮件提醒”可直接定位到邮箱设置，尚未保存的任务内容会保留。邮箱区域有“应用并保存设置”“邮件设置教程”和“返回事件详情”，保存后可返回原任务继续编辑。独立详情窗也支持这个入口。

同一个任务时段只自动发送一次。失败不自动重发；检查配置后，可修改任务开始时间或提醒提前量，形成新的提醒时段。发信过程中意外退出可能留下“结果待确认”，不会自动重发，避免重复邮件。

## 窗口与本地保存

右上角三个按钮是真实的最小化、最大化/还原、退出。小提醒窗口可以拖动和关闭，主窗口最小化后仍可提醒。退出应用或电脑休眠后不提醒、不发邮件；安装版可在设置中按需开启开机自启动，没有独立系统后台服务。

## 检查与安装更新

设置顶部的“应用更新”显示当前版本。点击“检查更新”查看新版与更新内容，点击“下载新版”后显示进度，下载中可取消。校验通过后点击“保存并退出安装”，软件会先保存日程、对话和未提交草稿，再退出覆盖升级并重新打开。保存或校验失败时不会开始安装，个人记录保留。可选“启动时检查新版”默认关闭，勾选并保存后下次启动生效；只检查，不自动下载，正常退出也不自动安装。

更新需要维护者先在 GitHub Releases 发布新安装包和更新清单；本机修改源码不会自动改变已安装的软件。免安装预览只支持检查与打开官方发布页，需下载完整 ZIP 并保留原“预览数据”。网络失败时可继续用当前版本，稍后重试或手动下载安装包覆盖升级。

任务和偏好在当前 Windows 用户的应用数据目录（%APPDATA%\Shixu）保存。密钥和邮箱授权码使用 Windows 系统加密保存，同一 Windows 用户下其他程序仍可能有权访问，请妥善保护电脑。删除应用文件夹不会自动清除用户数据。

0.6.2 起，同一个数据目录只允许一个新版实例运行，再次打开会回到原窗口；旧版仍需先手动退出。记录写入前会保留上一份有效的 .bak 备份，启动时发现文件损坏会尝试恢复并显示提示，同时保留损坏的原文件。若当前文件和备份都无法恢复，应用停止启动，避免空白记录覆盖原数据。备份仅保留上一份，不能替代你自行进行的完整备份。

保存失败时，页面上方会持续显示提示并提供“重试保存”，当前修改仍保留在窗口内；失败后请求退出会保留窗口。使用关闭按钮或系统关闭操作时，软件会先保存。事件和计划详情中尚未确认的填写会作为独立草稿保存在本机，重新打开相应任务或新建入口可继续填写，草稿不会自动成为日程。输入后约 350 毫秒保存一次；突然断电或强制结束进程仍可能丢失最后一小段输入。

新手教程、语音转写、任务时长编辑、计划详情和图表导出窗口都可以拖动并关闭；专注结束与任务提醒的独立小窗可拖动系统区域并关闭。自定义上传背景暂只在当前打开期间生效。没有自有 API 或 SMTP 配置时，不能验证真实 AI 回答、云端识别质量和实际邮件送达。设置中可重新打开教程。

## 普通规划与课表

课程默认只作为占用时间。普通规划不会重新修改整学期课程，也不会让已确认课程与自己产生冲突。需要调课时，请写明课程名称和原日期，例如“把11月2日的大学物理实验改到14:00–15:00”；只修改对应课程，其他课程和原有教学内容保留。模型仅收到相关日期的精简占用，整学期课表仍在本地用于校验。

旧版对话中已确认课表的重复草案会在恢复时清理，未确认的手动改动保留；这不会自动恢复已经被旧版确认保存的错误调课。已保存记录仍以本机日程为准，可按学校课表手动核对并调整。
