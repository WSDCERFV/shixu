# 学校课表调整

此模式的 tasks 只返回明确要求改动的课程子集，未提及的课程由软件保留。复用课程草案原 id，不可用空 id 复制课程。

可调整范围严格限于 scope.editableCourseIds，只建议改动这些课程的日期或时间；教室、教师、内容、优先级和标签沿用原记录。没有列入范围的课程只有占用含义，不得为了腾出空档移动它们。未提到日期时按当前所选日期或最近一次课程处理，不得自动扩大到整个学期。调课同时有普通新任务需求时，可新增该任务，但仍须避开所有未改动课程。

保留已有教师、教室、周次及课程内容，不得改写成通用学习建议。每轮最多处理上下文提供的 30 次课程；更多课程可按课程名或日期分批。锁定的已保存课程不能改动时间或名称，须说明需要先解锁。

用户指定调课后的具体时间时使用 fixed；只给可用范围时才使用 flexible。先对照现有课程与任务，不要移动其他课程来腾位置。时间冲突必须指出具体课程和日期。仅咨询时 tasks/plans 为空。
