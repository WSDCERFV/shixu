# 时序 0.9.3 · 免安装预览

解压整个文件夹后，双击“时序预览.exe”，不用安装，也不用安装 Node.js。不要在压缩包里直接运行，不要只拷贝其中的 exe。

首次以极简模式打开，顶部可切换普通模式。可以先跳过新手教程，直接查看当日计划、周计划和右侧 AI 输入区。新用户没有测试任务。

日程、偏好、对话和密钥存放在本文件夹下的“预览数据”，与安装版的个人记录分开。首次空白，之后可以关闭再打开继续体验。请把整个文件夹放在可写的位置。预览数据不会自动迁移到安装版；删除整个预览文件夹前，请先保留你需要的记录。

AI 对话可在 API 管理中选择模板并填写自己的密钥，也支持自定义接口。已内置规划技能和本地时间冲突检查。发送、等待、逐步回复、停止和失败均有反馈，模型提供的思考内容在开始回答后折叠。学校抓取需登录后明确选择学期并核对日期，读取后先预览。系统语音听写使用 Win+H。任务详情、草案预览与确认、日程编辑等使用与安装版相同的代码；本版关闭开机自启动设置，不注册 Windows 启动项。

当前文件未代码签名，Windows 可能显示未知发布者。关闭预览后即可移动整个文件夹。

设置中的“应用更新”可检查公开版本并打开官方发布页，不会把预览版自动转换为安装版。更新预览时先关闭程序，下载并解压完整 ZIP，将原“预览数据”文件夹完整保留到新文件夹，再打开新版；不要只替换 exe。安装版则支持在软件内下载更新，保存后退出覆盖安装。
